## Overview

Output Portal Granular Manager provides a dedicated preset browser and sample source organizer for Output Portal, the granular effects plugin. It helps producers manage Portal's large factory preset collection, organize custom audio sources imported for granular processing, and save and recall complex multi-parameter Portal states as named presets.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Output Portal Granular Manager** delivers the features you need in a clean, intuitive package.

> Official website: [output.com](https://output.com)

## Key Features

| Feature | Description |
|---------|-------------|
| **Preset Browser** | Browse and filter all Portal factory and user presets by texture type |
| **Source Library** | Organize audio files imported as granular source material in Portal |
| **State Recall** | Save and load complete Portal parameter states as named snapshots |
| **Quick Audition** | Preview how a source file sounds through Portal before committing |
